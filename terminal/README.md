# Terminal Setup

## iTerm2 (recommended)

### Import profile

1. Open iTerm2
2. **Settings > Profiles > Other Actions > Import JSON Profiles**
3. Select `devkit/terminal/iterm2-profile.json`
4. Set "devkit" as the default profile

### Profile details

| Setting | Value |
|---------|-------|
| Font | Monaco 12pt |
| Theme | Light (near-white background, dark text) |
| Window | 80 columns x 25 rows |
| Transparency | None (opaque) |
| Cursor | Non-blinking block |

## Terminal.app (alternative)

Uses the built-in **Homebrew** theme (green on black). No config file needed - just set it:

1. Open Terminal
2. **Settings > Profiles > Homebrew > Default**
